# Immersive Tutorial and Terminal Help Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an always-available terminal help system and a data-driven, diegetic prologue tutorial that confirms correct investigation direction with restrained window-border and audio feedback without displaying a task checklist or revealing puzzle answers.

**Architecture:** A focused `TutorialRuntime` interprets `tutorialFlow` data from the active case and observes normalized player actions. Apps and `CaseRuntime` emit facts; `main.gd` routes them into the tutorial runtime, delivers narrative messages, triggers sensory feedback, and persists tutorial state. `TerminalCommandRouter` owns generic command help and typo recovery, while all case-specific tutorial prose remains in JSON generated by `tools/generate_content.py`.

**Tech Stack:** Godot 4.7.1, GDScript, Control/RichTextLabel UI, AudioStreamGenerator, strict JSON case data, `user://save.json`, existing headless GDScript test runner.

```gdscript
class_name TutorialRuntime
extends RefCounted

signal step_advanced(step: Dictionary, deliveries: Array)
signal feedback_requested(app_id: String, style: String, sound: String)
signal nudge_requested(delivery: Dictionary)

var case_id := ""
var messages: Dictionary = {}
var steps: Array = []
var current_index := 0
var completed_steps: Dictionary = {}
var completed_milestones: Dictionary = {}
var consumed_messages: Dictionary = {}
var consumed_fallbacks: Dictionary = {}
var observed_facts: Dictionary = {}
var current_step_elapsed := 0.0
var skipped := false
```

Implement `configure`, `observe`, `tick`, `get_current_step_id`, `get_help_text`, `is_complete`, `is_skipped`, `skip`, `restart`, `to_save_data`, and private matching helpers. Support leaf conditions plus `allOf` and `anyOf` arrays. Store facts under a stable key composed from type, target, and sorted metadata JSON. A future action is recorded but only advances when it satisfies the current step; after a real advance, silently skip later steps already satisfied by recorded facts and emit at most one feedback request for the call.

`tick(delta)` increments only the active step timer. When `fallback.afterSec` is reached, emit its referenced delivery once and record it in `consumed_fallbacks`. Evaluate top-level `tutorialFlow.milestones` independently of step completion; a milestone can request a one-time feedback pulse without changing `current_index`. Persist elapsed time, consumed fallbacks, and completed milestones.
